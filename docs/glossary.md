# Glossary (junior-friendly)

| Term | Meaning |
|---|---|
| **SIEM** | Security Information and Event Management – collects logs, detects, supports investigation (Microsoft Sentinel) |
| **SOAR** | Security Orchestration, Automation and Response – automated playbooks |
| **XDR** | Extended Detection and Response – correlates signals across endpoint, identity, email, cloud (Microsoft Defender XDR) |
| **KQL** | Kusto Query Language used in Log Analytics, Sentinel and Defender hunting |
| **Log Analytics workspace** | Azure store where logs live and KQL runs |
| **Entra ID** | Microsoft's cloud identity service (formerly Azure AD) |
| **Password spray** | Trying a few common passwords against many accounts to avoid lockouts |
| **MFA** | Authentication using two or more different factor types |
| **Conditional Access** | If-then access policies evaluated at sign-in |
| **PIM** | Privileged Identity Management – just-in-time, time-bound privileged roles |
| **RBAC** | Role-based access control – permissions via roles at a scope |
| **Managed identity** | Identity for Azure resources so apps need no stored secrets |
| **MITRE ATT&CK** | Public catalogue of attacker tactics and techniques |
| **IOC** | Indicator of compromise (IP, hash, domain) |
| **False positive** | Alert on benign activity |
| **Synthetic data** | Made-up data created for learning; no real people or systems |
| **Bicep** | Azure's infrastructure-as-code language that compiles to ARM templates |
| **Azure Policy** | Service that audits/denies resource configurations against rules |
